Variantes

Modelos que declaram variantes no catálogo aceitam o sufixo #<variant> — em aliases, refs e ids simples.

Uso

request 
{"model": "claude-opencode-go-my-model#high", "max_tokens": 512, …}

A variante é validada contra o catálogo: label desconhecido devolve 404 com a lista das disponíveis; modelo sem variantes devolve erro explícito. Nunca é ignorada em silêncio.

Tradução por protocolo

Campo usado por protocolo
protocolocampo no upstreamdetalhe
Chat Completionsreasoning_effortLabels fora do enum da OpenAI (xhigh, max) saturam para high; none remove o parâmetro.
Responses APIreasoning + includeObjeto {"effort": …} mais os include declarados pela variante.
Anthropic (passthrough)thinking{"type":"adaptive","display":"summarized"} para variantes com thinking; {"type":"disabled"} para none.

Uma variante sem representação segura no Messages API (só reasoningEffort) retorna 400 em vez de ser silenciosamente ignorada. A variante é aplicada sobre o corpo já traduzido, porque os tradutores descartam campos que não conhecem.
