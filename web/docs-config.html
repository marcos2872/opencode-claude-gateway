config.toml

Arquivo em ~/.config/opencode-claude-gateway/config.toml, criado no primeiro run com todas as opções comentadas (parseando para os defaults). Um arquivo inválido é erro fatal — nunca default silencioso.

Quando é lido

No boot. Depois de editar: ocg --stop && ocg --start, ou systemctl --user restart ocg quando o auto-start está ligado.

Overrides de ambiente: --port/OCG_PORT, --config/OCG_CONFIG, e OCG_AUTH_TOKEN (não-vazio sobrescreve o arquivo e é herdado pelo daemon filho).

Há duas superfícies independentes: o template semeado no primeiro run e o config.example.toml completo do repositório. Os dois são validados por teste.

Todas as chaves

Chaves do config.toml e padrões
chavepadrãoo que faz
port3737Porta do gateway (sempre 127.0.0.1).
auth_token""Vazio = aceita qualquer credencial. Setado = todo endpoint menos GET /health exige o token. Ver Autenticação.
default_model""Modelo quando a request omite model. Vazio = primeiro alias alfabético — hoje costuma ser um claude-github-copilot-…. Fixe um que funcione.
opencode_bin"opencode"Binário do pareamento, do catálogo fallback e da descoberta do DB.
opencode_pairtruePareia com o serviço v2 e lê catálogo/providers/credenciais por HTTP. false = CLI + SQLite read-only. Ver Pareamento.
opencode_url""URL explícita do servidor v2. Vazio = descobre pelo serviço selecionado.
include_free_tierfalseMostra modelos opencode/* no /v1/models. Dão 403 fora do OpenCode.
desktop_aliasesfalseReescreve o id anunciado para furar a denylist do picker do Desktop (deepseek → d-eepseek). Só o id muda.
cli_shield_aliasestrueReescreve o spelling de família nos ids (claude-sonnet → cs) para as chamadas de fundo do CLI não caírem no Copilot.
mock_classifierfalseResponde localmente o classificador do auto-mode e os probes de 1 token. Tradeoff: a revisão de segurança do auto-mode sempre responde "allow".
connect_timeout_secs30Timeout TCP/TLS — provedor inalcançável falha rápido.
request_timeout_secs3600Timeout total, incluindo streaming. Generoso de propósito: um turno longo com reasoning fica aberto minutos.
[aliases."<id>"]—Alias manual (opencode + display_name/description). Precede os automáticos. Ver Aliases.
[disabled] models[]Refs escondidas do /v1/models. Não bloqueia o match por id simples.
[tiers."<ref>"]—Tier de família (haiku/sonnet/opus/fable/mythos) anunciado no /v1/models. Ver Tiers.

Esqueleto completo

config.toml 
# gateway
port = 3737
auth_token = ""
default_model = ""

# opencode v2
opencode_bin = "opencode"
opencode_pair = true
opencode_url = ""

# visibilidade do catálogo
include_free_tier = false
desktop_aliases = false
cli_shield_aliases = true
mock_classifier = false

# transporte
connect_timeout_secs = 30
request_timeout_secs = 3600

# [aliases."claude-my-model"]
# opencode = "opencode-go/some-model"

# [tiers."opencode-go/some-model"]
# tier = "haiku"
# family_default = true

# [disabled]
# models = ["opencode-go/hy4-preview"]
