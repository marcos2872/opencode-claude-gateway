Claude Desktop

No Linux (porte comunitário — a Anthropic só distribui Desktop para Mac/Windows) a configuração 3P é um arquivo managed lido no boot, sem menu de Developer Mode.

Linux: managed-settings.json

/etc/claude-desktop/managed-settings.json 
{
  "inferenceProvider": "gateway",
  "inferenceGatewayBaseUrl": "http://127.0.0.1:3737",
  "inferenceCredentialKind": "static",
  "inferenceGatewayApiKey": "dummy",
  "inferenceGatewayAuthScheme": "bearer",
  "modelDiscoveryEnabled": true
}

inferenceGatewayApiKey é o valor do auth_token do gateway (ou qualquer placeholder se vazio). bearer e x-api-key são ambos aceitos.

Permissões são eliminatórias: arquivo regular, root:root, sem escrita para grupo/outros — vale também para o diretório. 0600 não funciona: o app roda como seu usuário e precisa ler o arquivo. Use 0644.

shell — permissões + reinício 
$ ocg --start
$ sudo chown root:root /etc/claude-desktop/managed-settings.json
$ sudo chmod 0644 /etc/claude-desktop/managed-settings.json # 0600 dá EACCES
$ sudo chmod 0755 /etc/claude-desktop

Feche o Desktop por completo e reabra: a config só é lida no boot. Na tela de login aparece Continue with Gateway (saia da conta Anthropic se já logado).

A base URL começa sem sufixo /v1 (o app anexa /v1/messages) e usa 127.0.0.1, não localhost. Se der 404, veja no log do ocg qual path chegou.

Mac / Windows (builds oficiais)

Help → Troubleshooting → Enable Developer Mode (reinicia com o menu Developer), depois Developer → Configure Third-Party Inference com os mesmos valores: provider Gateway, Static API key, scheme Bearer. Em builds recentes o toggle pode estar em avatar → Settings → Developer Mode.

Modelos visíveis no picker

O Desktop valida cada id descoberto: precisa conter claude/anthropic/família e não conter nenhum token da denylist embutida (deepseek, kimi, glm, gpt, grok, qwen, gemini, minimax, …). Listas explícitas (inferenceModels) passam pelo mesmo filtro.

Para listar tudo, ative a evasão no gateway:

config.toml 
# reescreve deepseek -> d-eepseek etc. só no id anunciado
desktop_aliases = true
# sem default_model, requests sem "model" caem no 1º alias alfabético
default_model = "claude-opencode-go-muse-spark-1-3-contributor"

Reinicie o gateway e o Desktop. Só o id anunciado muda; refs, display names e resolução ficam intactos. Se a Anthropic ampliar a denylist, novos tokens podem cair de novo — o log Model discovery: N found; picker = M denuncia.

Títulos e chamadas de fundo

O Desktop gera títulos com a classe small_fast, escolhendo o primeiro modelo com tier haiku, senão sonnet, senão opus. Sem tier, cai num match por substring e queima a quota do primeiro *sonnet* alfabético. Configure [tiers] para apontar isso ao modelo barato.

Diagnóstico

shell 
$ grep -E 'managed-settings|gateway|discovery|3p' ~/.config/Claude/logs/main.log | tail -n 20
# EACCES = permissão (precisa 0644 root:root)
# rejeição de chave = nome/valor inválido
