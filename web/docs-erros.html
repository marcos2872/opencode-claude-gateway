Erros e diagnóstico

Primeiro o /health, depois o log. A maioria dos "erros" é catálogo não carregado, credencial ausente ou uma chamada de fundo que você não fez.

Onde olhar

  • Saúde: curl -s http://127.0.0.1:3737/health | jq — models: 0 logo após o boot costuma ser o serviço do OpenCode aquecendo.
  • Daemon: ~/.local/share/opencode-claude-gateway/ocg.log (só-append).
  • Foreground: RUST_LOG=opencode_claude_gateway=debug ocg --serve.

Para conferir o cache de prefixo do upstream, procure upstream cache usage e compare cached_input_tokens com input_tokens.

Avisos esperados

Auto-mode "session isn't eligible…"

Esperado com qualquer gateway: a Anthropic moveu as checagens do classificador do auto-mode para server-side, e sessões via 127.0.0.1 não as usam — o upstream é o OpenCode Go. Pressione Enter (suspenso por 24h naquela máquina) ou silencie com CLAUDE_CODE_AUTO_MODE_SERVER=0 no env do settings.

"There's an issue with the selected model"

Mensagem genérica do CLI disparada por qualquer 4xx cujo texto cite o modelo (indisponibilidade pontual ou limite do provedor). Não significa que o alias sumiu: /v1/models e /health continuam normais nesses momentos.
