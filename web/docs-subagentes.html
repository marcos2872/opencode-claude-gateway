Subagentes

Sem model próprio, o subagente herda o modelo da conversa. Isso é o padrão — não é uma garantia.

Ordem de resolução

  1. model passado na invocação;
  2. model do agente (inherit é válido);
  3. CLAUDE_CODE_SUBAGENT_MODEL;
  4. modelo da conversa principal (ou do subagente pai, se aninhado).

Built-ins têm regras próprias: Explore tem tratamento especial quando o pai roda Fable, statusline-setup usa Sonnet e claude-code-guide usa Haiku.

CLAUDE_CODE_SUBAGENT_MODEL_FORCE

  • FORCE=1 sem CLAUDE_CODE_SUBAGENT_MODEL: todos usam o modelo da conversa principal (exceto o built-in do Explore).
  • FORCE=1 com um id: todos usam aquele id fixo, que não acompanha o /model da sessão.

Fixar um id do gateway

Subagentes podem escolher um snapshot de modelo que o OpenCode não oferece, resultando em model_not_found. O caminho confiável é fixar um id que exista no catálogo do gateway.

shell 
# copie um id exatamente como aparece
$ curl -s http://127.0.0.1:3737/v1/models | jq -r '.data[].id' | sort
export CLAUDE_CODE_SUBAGENT_MODEL="SEU_ID_EXATO_DO_V1_MODELS"
export CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1
claude

Inclua o sufixo [1m] quando ele aparecer no id. Para persistir, adicione as duas chaves ao bloco env do ~/.claude/settings.json e reabra o CLI.

Para seguir o modelo da sessão em vez de fixar um id, use model: inherit nos agentes que você controla, ou FORCE=1 sem definir CLAUDE_CODE_SUBAGENT_MODEL — com a ressalva do Explore.
