O que é o ocg

Um gateway local, compatível com a API da Anthropic, que expõe os modelos do OpenCode v2 ao Claude Code e ao Claude Desktop. Ele escuta só em 127.0.0.1 e nunca fala com a Anthropic: o upstream é o backend Go/Console do OpenCode.

  • Pareia com o serviço local do opencode e reaproveita as credenciais que você já tem.
  • Traduz a Messages API para o protocolo de cada modelo — passthrough Anthropic, Chat Completions ou Responses API — e de volta, streaming incluído.
  • Resolve o modelo por alias, ref provider/model ou id simples, com variantes #variant.

Para a apresentação visual e o diagrama da tradução, volte à página inicial. Os mesmos textos existem em Markdown em docs/, no repositório.
