Janela de contexto

O gateway anuncia a janela do catálogo (limit.context) como context_window e, para janelas ≥ 1M, como sufixo [1m] no id — o único que a mainline do Claude Code lê.

O que o gateway não resolve

Janelas abaixo de 1M e o aviso "X" isn't described by this version's model catalog não são resolvidos pelo gateway: ids sintéticos não constam do catálogo embutido do CLI, que assume 200k. Defina a janela no lado do Claude Code.

modelOverrides

~/.claude/settings.json 
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:3737",
    "ANTHROPIC_AUTH_TOKEN": "dummy"
  },
  "modelOverrides": {
    "claude-opencode-go-kimi-k2-7-code": {
      "behavesAs": "claude-sonnet-4-5",   // herda janela/uso do Claude mais próximo
      "inputWindowHint": 262144          // ou fixe a janela em tokens
    }
  }
}

Alternativas: sufixar manualmente "model": "claude-...[1m]" (só para janelas de 1M — o gateway remove o sufixo ao resolver) ou, como último recurso, CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1, que desliga a checagem para ids desconhecidos ao custo da conta real de tokens.

Verificar

shell 
$ curl -s http://127.0.0.1:3737/v1/models \
    | jq '.data[] | {id, context_window}'
