Claude Code CLI

Três variáveis e o CLI fala com o gateway. O modelo é escolhido no /model, alimentado pelo /v1/models.

Variáveis de ambiente

shell — sessão atual 
export ANTHROPIC_BASE_URL=http://127.0.0.1:3737
export ANTHROPIC_AUTH_TOKEN=dummy
export CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1  # habilita entradas no /model
claude

ANTHROPIC_AUTH_TOKEN é a credencial do gateway (auth_token), não uma chave da Anthropic. Por padrão o gateway aceita qualquer valor em loopback, então dummy basta; se auth_token estiver setado, o valor precisa ser igual.

Persistir em settings.json

~/.claude/settings.json — escopo do usuário 
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:3737",
    "ANTHROPIC_AUTH_TOKEN": "dummy",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1"
  }
}

Se já existe um ANTHROPIC_BASE_URL nesse arquivo apontando para outro backend, o env do arquivo vence os export do shell. Para usar o gateway só numa sessão, passe um settings temporário: claude --settings '{"env":{…}}' — o --settings tem precedência.

Descoberta de modelos

O /model lê o GET /v1/models. A descoberta só mantém ids contendo claude/anthropic — os aliases automáticos já contêm. Janelas ≥ 1M aparecem como claude-...[1m]; selecione exatamente a forma anunciada, senão o picker mostra Custom model (funciona na API, mas sem nome).

Ids blindados e chamadas de fundo

O CLI resolve modelos de fundo (small-fast e fallbacks de família) canonicando os ids descobertos por substring. Na prática, as linhas do Copilot são as primeiras em ordem alfabética e casam claude-sonnet-5, então side queries caem nelas — daí o 429 quota exceeded com max_tokens: 64000 e tools: [] sem você ter escolhido o Copilot.

Com cli_shield_aliases = true (padrão) o gateway reescreve o spelling de família nos ids anunciados — claude-github-copilot-claude-sonnet-5 vira claude-github-copilot-cs-5 — sem tocar em refs, display names ou resolução. A ref direta continua funcionando para usar o Copilot de propósito.

Opt-out: cli_shield_aliases = false mantém o spelling antigo, útil se algum fluxo externo depende dos ids históricos.

Complemento: fixe o small-fast no modelo barato para o background nunca consultar a família por fallback:

~/.claude/settings.json — env 
{
  "env": {
    "ANTHROPIC_SMALL_FAST_MODEL": "claude-opencode-go-muse-spark-1-3-contributor[1m]",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opencode-go-deepseek-v4-1-flash",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-opencode-go-glm-5-3-flash",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-opencode-go-muse-spark-1-3-contributor"
  }
}

Para prender de vez os ids de primeira parte, veja a receita de Aliases.

Verificar antes de abrir o CLI

shell 
# 0. catálogo carregado?
$ curl -s http://127.0.0.1:3737/health            # ok e models != 0
$ curl -s http://127.0.0.1:3737/v1/models | jq -r '.data[].id' | sort
# 1. chat de ponta a ponta
$ curl -s -X POST http://127.0.0.1:3737/v1/messages \
    -H 'content-type: application/json' \
    -d '{"model":"claude-opencode-go-glm-5-3-flash","max_tokens":64,"messages":[{"role":"user","content":"Say hi"}]}'

/status dentro do Claude Code deve mostrar a sua base URL.
