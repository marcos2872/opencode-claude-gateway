Aliases

Todo modelo habilitado ganha um id claude-<provider>-<model>. Quando o Claude pede um id que não existe, o gateway adivinha — e alias manual é como impedir a adivinhação.

Automático

Nada a configurar. O prefixo claude- é obrigatório (o discovery do Claude Code só mantém ids contendo claude/anthropic) e janelas ≥ 1M ganham [1m] — o único sufixo que a mainline lê.

Linhas com o mesmo provider/model mas id distinto (ex. opus-4.8 e opus-4.8-fast) ganham aliases separados, cada um com seus headers/body do catálogo. Ospellings de família podem ser blindados por cli_shield_aliases (claude-sonnet → cs) para o CLI não resolve-las por substring — ver CLI.

Manual e precedência

[aliases."<gateway-id>"] tem precedência sobre o automático para o mesmo id. Duas consequências práticas:

  • Um alias manual consome a ref. Se você aponta claude-x para opencode-go/glm-5.3-flash, o alias automático daquele modelo some do /v1/models. Re-declare o canônico para manter os dois.
  • A ref é o modelID exato — glm-5.3-flash (com ponto), não o slug do alias (glm-5-3-flash). Com a ref errada o alias aparece no /v1/models mas a resolução volta ao id simples, em silêncio.
config.toml 
[aliases."claude-meu-modelo"]
opencode = "opencode-go/glm-5.3-flash"
display_name = "GLM 5.3 Flash"
description = "via ocg"

Por que fixar ids de primeira parte

O Claude Code manda ids hardcoded por conta própria: side queries de título, small_fast, o classificador do auto-mode e os fallbacks de família. Eles não passam por default_model nem por tiers — caem no match por id simples, que pega a primeira linha ordenada por provider/model:

  • claude-sonnet-5 → github-copilot/claude-sonnet-5, com o WARN de ambiguidade;
  • ids que só existem no free-tier → opencode/*, que dá 403 fora do OpenCode.

Como o alias manual vence o id simples, cada família pode ser presa a um modelo que você paga:

config.toml — prendendo as chamadas de fundo 
# haiku: small_fast, títulos, background
[aliases."claude-haiku-4-5"]
opencode = "opencode-go/muse-spark-1.3-contributor"
[aliases."claude-haiku-5-5"]
opencode = "opencode-go/muse-spark-1.3-contributor"

# sonnet
[aliases."claude-sonnet-4-5"]
opencode = "github-copilot/gpt-6-luna"
[aliases."claude-sonnet-4-6"]
opencode = "github-copilot/gpt-6-luna"
[aliases."claude-sonnet-5"]
opencode = "github-copilot/gpt-6-luna"
[aliases."claude-sonnet-5-5"]
opencode = "github-copilot/gpt-6-luna"

# opus (inclui o id do classificador do auto-mode)
[aliases."claude-opus-4-8"]
opencode = "opencode-go/deepseek-v4.1-flash"

# fable
[aliases."claude-fable-5"]
opencode = "opencode-go/deepseek-v4.1-flash"

# canônicos: um alias manual consome a ref, então re-declare para o
# alias automático do modelo não sumir do /v1/models
[aliases."claude-opencode-go-muse-spark-1-3-contributor"]
opencode = "opencode-go/muse-spark-1.3-contributor"
[aliases."claude-github-copilot-gpt-6-luna"]
opencode = "github-copilot/gpt-6-luna"
[aliases."claude-opencode-go-deepseek-v4-1-flash"]
opencode = "opencode-go/deepseek-v4.1-flash"
  1. Use o modelID exato em cada ref.
  2. Cubra todas as variantes da família — um id novo não listado traz a adivinhação de volta.
  3. Re-declare o canônico de cada modelo consumido.
  4. Reinicie o gateway (config lido no boot).

Conferindo o destino real

O log upstream ok mostra o id que o cliente pediu. Quem revela o ref resolvido é upstream cache usage:

shell 
$ RUST_LOG=opencode_claude_gateway=debug ocg --serve
$ curl -s -X POST -H 'x-api-key: TOKEN' -H 'content-type: application/json' \
    -d '{"model":"claude-sonnet-5","max_tokens":16,"messages":[{"role":"user","content":"hi"}]}' \
    http://127.0.0.1:3737/v1/messages > /dev/null
# esperado: upstream cache usage ... opencode_ref=github-copilot/gpt-6-luna

O WARN ambiguous model id deve sumir depois de configurar. Limite: a lista é mantida à mão e as refs envelhecem com o catálogo (ocg --refresh lista as atuais).

[disabled]

Esconde refs do picker sem apagar a linha do catálogo: o alias some do /v1/models e nunca é escolhido como default, mas a ref direta continua resolvendo.

Não é allowlist. O catálogo continua participando do match por id simples, então desabilitar github-copilot/claude-sonnet-5 não impede uma request com "model":"claude-sonnet-5" de ir para ele. Com alias desabilitado, use a ref direta — o alias antigo vira 404.
