Tiers

[tiers] anuncia anthropic_family_tier no /v1/models. É metadado para o Claude Desktop escolher as chamadas de fundo — não é roteamento do CLI.

Por que existe

O Desktop gera o título de cada conversa em background com a classe small_fast: escolhe o primeiro modelo descoberto com tier haiku, senão sonnet, senão opus — e ignora o modelo da sua sessão. Sem tier anunciado, ele cai num match por substring no id e resolve no primeiro *sonnet* alfabético (hoje a linha do Copilot), queimando a quota dele a cada título.

Configurar

config.toml 
# prefira a ref provider/model: sobrevive às renomeações automáticas
[tiers."opencode-go/muse-spark-1-3-contributor"]
tier = "haiku"
family_default = true

[tiers."github-copilot/claude-sonnet-5"]
tier = "sonnet"

A chave casa gateway id ou ref provider/model, como o [disabled]. Prefira a ref, que sobrevive às renomeações automáticas (cli_shield_aliases, desktop_aliases).

Tiers válidos: haiku, sonnet, opus, fable, mythos — qualquer outro valor é erro de config. Aliases sem mapeamento não anunciam tier; nada quebra.

Verificar

shell 
$ curl -s http://127.0.0.1:3737/v1/models \
    | jq '.data[] | select(.anthropic_family_tier != null) | {id, anthropic_family_tier, is_family_default}'

O CLI ignora tiers

O Claude Code descarta anthropic_family_tier do discovery — o schema de cache dele guarda só id, nome, descrição e janela. Para o CLI, use ANTHROPIC_DEFAULT_*_MODEL, ANTHROPIC_SMALL_FAST_MODEL e os aliases de fixação de Aliases.
